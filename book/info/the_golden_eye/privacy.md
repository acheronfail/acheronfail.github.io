# The Golden Eye Privacy Policy

The Golden Eye is an OBS Studio plugin for recording GoldenEye N64 speedruns. It includes an optional YouTube upload feature.

## What information is collected?

The Golden Eye does not collect any personal information.

The plugin does not read, store, save, sell, share, or transmit Google user data to the developer or to any third-party server.

## How Google access is used

If a user chooses to upload a video to YouTube, The Golden Eye uses Google OAuth only to authorize that upload through the YouTube Data API v3.

This access is used only for the user-requested upload. The plugin does not use Google access to read account details, inspect YouTube data, download data, or store user information.

## Data storage

The Golden Eye does not operate a backend service for user data and does not store Google user data. Everything is done locally on the user's computer.

Any video upload is sent to YouTube as requested by the user. After the upload request is complete, The Golden Eye does not retain Google user data.

## Data sharing

The Golden Eye does not share Google user data with anyone.

## Google API limited use

The Golden Eye uses Google API access only for the user-requested YouTube upload feature. It does not use Google user data for advertising, analytics, resale, sharing, or any unrelated purpose.
